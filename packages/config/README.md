# @nimia/config

Konfigurasi bersama (base `tsconfig.json`, dan nanti eslint preset) yang dipakai semua `apps/*`. Tujuannya supaya standar TypeScript/lint konsisten di seluruh monorepo tanpa duplikasi (prinsip "Maintainability" & "Avoid duplicated code" di project instructions).

Status: baru berisi `tsconfig.base.json`. Eslint preset bersama bisa ditambah nanti kalau `apps/studio` sudah butuh (Tahap 4+).
